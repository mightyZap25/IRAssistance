# [문서 2-9] 제조사 (Manufacturers) 분석서

## 1. 제조사 관리 기능 개요 및 목적
`ManufacturersPage` 컴포넌트는 ERP 시스템에서 부품을 생산하거나 공급하는 원천 제조사(Maker)의 마스터 데이터를 관리하는 화면입니다. 개발 부서나 설계 부서가 새로운 부품(Part)을 등록할 때 "어떤 회사의 규격품인지"를 지정하기 위한 기초 데이터베이스(Reference Data)로 활용됩니다.

---

## 2. 보기 방식 (View Mode) 및 UI 구조
고객사(Customers) 페이지와 유사하게 직관적이고 모던한 **그리드 카드(Grid Card) 뷰** 전용으로 렌더링됩니다.

- **그리드 레이아웃:** 브라우저 창 크기에 따라 반응형(Responsive)으로 동작하며, 1열에서 최대 3열(`lg:grid-cols-3`)까지 카드 리스트가 자동 정렬됩니다.
- **실시간 검색:** 화면 상단의 검색바(Search Bar)를 통해 제조사명(`Name`)을 입력하면, 서버에 다시 요청하지 않고 프론트엔드 메모리 상에서 실시간으로 카드가 필터링(`filteredManufacturers`)됩니다.
- **상호작용(Hover Effect):** 개별 카드에 마우스를 올리면 우측 상단에 숨겨져 있던 `수정(Pencil)` 및 `삭제(Trash2)` 액션 버튼이 나타나 사용자 경험(UX)을 깔끔하게 유지합니다.

---

## 3. 세부 내역 및 데이터 구조
개별 제조사 카드에 노출되는 주요 필드(Firestore `manufacturers` 컬렉션 스키마)는 다음과 같습니다.

### 3.1. 관리되는 핵심 필드
1. **제조사명 (Name):** (필수값) 카드의 타이틀이자 가장 굵고 큰 글씨로 표시됩니다.
2. **국가 (Country):** 제조사의 국적을 표기하며, 입력되지 않았을 경우 'Unknown Country'라는 대체 텍스트가 노출됩니다.
3. **웹사이트 (Website):** 등록된 URL이 있을 경우 클릭 가능한 `<a>` 태그 형태(새 창 열림)로 렌더링되어 사용자가 즉시 해당 제조사 사이트로 이동해 스펙을 확인할 수 있도록 돕습니다.
4. **설명 (Description):** 제조사의 주요 취급 품목이나 특이사항을 기재합니다. 텍스트가 너무 길 경우 카드 UI가 깨지는 것을 방지하기 위해 `line-clamp-2`(최대 2줄까지만 표시하고 말줄임표 처리) 스타일이 적용되어 있습니다.

---

## 4. 데이터 추가 / 수정 / 삭제 흐름
- **제조사 등록/수정 모달 (`ManufacturerModal`):**
  - 화면 내에서 페이지 이동 없이 팝업(Modal) 형태로 폼 입력 창이 열립니다.
  - "등록" 버튼 클릭 시 폼이 비워진 상태로 열리고, 카드 내 "수정" 버튼 클릭 시 기존 데이터가 채워진(`initialData`) 상태로 열립니다.
- **Firestore 연동 로직:**
  - 생성: `addDoc(collection(db, 'manufacturers'))` 호출. 이때 문서 생성 시간인 `CreatedAt` 필드가 시스템 내부적으로 자동 추가됩니다.
  - 수정: `updateDoc(doc(db, 'manufacturers', id))` 호출.
  - 삭제: 자바스크립트의 기본 `window.confirm` 대화상자를 띄워 사용자의 명시적 동의를 구한 뒤 `deleteDoc`을 통해 영구 삭제 처리합니다. 삭제 후 화면 목록(`setManufacturers`)에서도 즉각 필터링되어 사라집니다.
