### 1. ERP 핵심 마스터

# 부품 관리 (Part List) 사용자 매뉴얼

부품 관리 메뉴는 모든 원부자재, 반제품 및 완제품의 마스터 데이터를 등록하고 라이프사이클 및 변경 이력을 트래킹하는 PLM/ERP의 핵심 관제 센터입니다.

---

## 1. 개요 및 권한 정책

*   **메뉴 경로**: 사이드바 ➡️ **ERP** ➡️ **Parts (부품 관리)**
*   **주요 역할**: 전사 원부자재 규격 관리, 단가 및 위치 등록, 대체품 지정, 파급 효과 분석.
*   **권한 요구사항**:
    *   **일반 사원 (User/Guest)**: 부품 목록 조회, 상세 마스터 뷰 및 탭 정보(수불 이력 등) 조회 가능.
    *   **설계 엔지니어 (Engineer)**: 신규 부품 등록, 엑셀 일괄 추가(Import), 부품 수정, 리비전 변경 등록 가능.
    *   **부서 책임자 (Manager/Admin)**: 부품 등록 최종 승인(`Approve`을 통한 Active 상태 전환), 부품 삭제 가능.

## 2. 부품 리스트 화면 구성
![[part list.png]]
### 2.1 주요 검색 및 필터링 기능
*   **검색창**: 부품명 또는 Part ID를 즉시 필터링하여 검색합니다.
*   **수입품 전용 필터**: 해외 수입 자재(`IsOverseas === true`)만 필터링하여 리드타임 대비 자재 확보 현황을 볼 수 있습니다.
*   **정렬(Sorting)**: `Part ID`, `부품명`, `규격`, `단가` 컬럼 헤더 클릭 시 오름차순/내림차순 정렬을 지원합니다.
*   **뷰 모드 전환**: 
    *   **리스트 뷰(List View)**: 표 형식으로 수십 개의 항목을 조밀하게 비교 분석.
    *   **카드 뷰(Card View)**: 부품 상태(Lifecycle) 뱃지, 규격(Spec), 기본 보관 위치, 부품 단가를 시각화한 블록형 조회.

### 2.2 리스트 컬럼 및 레이블 정의
| 레이블명 | 필드 키 | 설명 |
| :--- | :--- | :--- |
| **Part ID** | `PartID` | 부품 식별 코드 (예: 원자재 `IRP-XXXX`, 반제품 `IRA-XXXX` 등) |
| **부품명** | `Name` | 부품 또는 어셈블리의 한글/영문 식칭 |
| **규격** | `Spec` | 상세 물리적 치수, 용량, 프로토콜 사양 (JSON 배열 또는 쉼표 뱃지 형식) |
| **대분류** | `Category` | 완제품 / 조립품 / 원자재 / 소모품 등 대분류 항목 |
| **분류** | `Class` | 세부 카테고리 (예: Mechanical, Electrical, PCB 등) |
| **타입코드** | `PartTypeCode` | 부품 형태 분류 코드 |
| **리비전** | `Rev` | 부품 설계 버전 (예: `1.0`, `1.1` 등) |
| **단위** | `Unit` | 측정 단위 (EA, Roll, Box, Kg 등) |
| **공급사** | `Maker` | 자재를 공급하는 업체 (Vendor) |
| **제조업체** | `Manufacturer` | 부품을 실제 생산하는 원제조사 (Manufacturer) |
| **제조사품번** | `MPN` | 제조업체에서 부여한 오리지널 파트 번호 (Manufacturer Part Number) |
| **모델번호** | `MFN` | 원제조사 모델명 |
| **담당자** | `Owner` | 해당 자재 및 도면을 관리하는 내부 엔지니어/담당자 |
| **단가** | `UnitPrice` | 부품 1개당 기준 단가 |
| **통화** | `Currency` | 단가 기준 화폐 단위 (KRW, USD 등) |
| **기본 보관 위치** | `DefaultLocation` | 창고 내 입고 시 배치될 기본 구역 (Bin/Rack 번호) |
| **생애주기 상태** | `Lifecycle` | 부품 승인 상태 (`Draft` ➡️ `Active` / `Obsolete`) |
| **가공/구매** | `ProcessType` | 사내 가공품(Make)과 구매 품목(Purchase) 구분 |
| **재질** | `Material` | 금속, 플라스틱 등 물리적 원자재 구성 성분 |
| **등급** | `Grade` | 자재 품질 또는 사양 등급 |
| **색상** | `Color` | 외관 색상 사양 |
| **비고** | `Description` | 특이 사항 및 참고용 서술 항목 |
| **수입품** | `IsOverseas` | 수입 품목 여부 (내수 / 수입) |
| **리드타임(일)** | `LeadTime` | 발주 후 입고 완료 시까지 소요되는 평균 일수 |

## 3. 부품 세부 마스터 뷰 (상세 우측 패널)

리스트에서 행을 클릭하면 우측에서 슬라이딩 아웃되는 상세 정보창입니다.
[PartsDetailPanel.jsx](file:///D:/workspace/IR_Assistant/src/components/PartsDetailPanel.jsx) 컴포넌트로 구현되어 있습니다.
![[부품 세부 마스터 뷰.png]]
### 3.1 헤더 액션 버튼
*   **승인 (Approve)**: `Draft` 또는 `ECO Pending` 상태인 부품을 `Active(승인완료/양산)` 상태로 업데이트합니다. (Manager 권한 전용)
*   **수정하기**: 해당 부품 정보를 수정하는 등록 폼 모달을 띄웁니다. (Engineer 권한 이상)
*   **리비전 전환 셀렉터**: 부품 마스터의 여러 버전(`Revision`) 목록 중 과거 리비전을 선택하여 당시의 단가, 규격, 첨부파일 이력을 즉각 비교 조회할 수 있습니다.

### 3.2 탭별 상세 제어 기능

#### ① 품질 기준 (QA Standards)
*   부품의 수입 검사(Receiving Inspection) 및 공정 검사 기준을 관리합니다.
*   **필수 항목**: 검사 항목(외관, 치수 등), 판정 기준, 검사 도구, 샘플링 레벨(AQL 등), 필수 인증(RoHS, CE, KC 등) 및 파일 링크.

#### ② 대체품 (Substitutes)
*   해당 자재 품절 및 수급 불안정 시 대체 투입이 가능한 호환 부품 리스트입니다.
*   **연동**: 대체 자재의 Part ID와 부품명이 표기되며, 즉시 해당 부품 상세 뷰로 전환할 수 있는 링크를 제공합니다.

#### ③ 파급 효과 (Impact Tree)
*   해당 부품이 설계 변경되거나 단종(Obsolete)될 때 영향을 받는 상위 조립품과 완제품 목록을 **계층 구조 트리(BOM Parent Tree)**로 시각화합니다.
*   가장 하단의 자재부터 최종 완제품(`Top-Level`)까지의 소요량(Qty)과 상위 조립 명칭을 재귀적으로 노출하여, 설계 변경 결정 전에 선제적 리스크를 분석합니다.

#### ④ 파생 모델 (Derivatives)
*   동일한 베이스 도면(`BasePartID`)을 공유하며 파생되어 기획된 자재 및 모델 리스트를 보여줍니다.

#### ⑤ BOM 사용처 (Used In)
*   해당 부품이 직계 하위 부품으로 포함되어 있는 상위 BOM 부모 목록(Parent PartID, Parent Name, 소요량)을 단층(1-Level) 테이블로 명시합니다.

#### ⑥ 수불 이력 (InOut Transactions)
*   창고 입고, 생산 불출, 재고 조정, 출하 등으로 인해 발생한 실시간 재고 변동 내역입니다.
*   **표시 항목**: 거래 일자, 거래 구분(입고/출고/조정 등), 수량, 이전고/현재고, 참조 문서 번호(PR/PO).

#### ⑦ 변경 이력 (ECO History)
*   설계 변경 통보(ECO)에 의해 해당 부품의 사양이나 리비전이 변경된 과거 결재 문서 목록입니다. ECO 번호, 작성자, 승인일 및 변경 사유를 타임라인 순으로 보여줍니다.

## 4. 부품 등록 및 수정 폼 모달

[PartFormModal.jsx](file:///D:/workspace/IR_Assistant/src/components/PartFormModal.jsx)를 통해 신규 데이터 추가 및 수정 작업을 제어합니다.

### 4.1 입력 항목 및 유효성 검사 (Validation)
*   **Part ID (필수)**: 중복되지 않는 고유 키. `PartID` 자동 생성기 또는 설계 규칙에 따른 입력 필요.
*   **부품명 (필수)**: 미입력 시 등록 불가.
*   **대분류 및 세부 분류 (필수)**: 카테고리에 따라 BOM 빌드 시 하위 구성 필터가 달라집니다.
*   **단가 및 통화**: 소수점 입력을 지원하며, 기본값은 `KRW`입니다.
*   **수입 자재 여부**: 체크 시 `IsOverseas` 필드가 활성화되며, **해외 리드타임(일)** 입력을 필수로 유도합니다.
*   **도면 및 데이터 시트**: Google Drive 도면 링크 및 이미지 파일 경로를 첨부할 수 있습니다.
*   **기본 보관 위치**: 창고 내 랙 번호 입력.
