# 개인 Task 관리 매뉴얼 (TasksPage.md)

## 1. 메뉴 개요 및 경로
* **메뉴 경로**: 협업 도구 > 개인 Task 관리 (또는 나의 할 일 목록)
* **화면 역할**: 프로젝트 공정 외에 로그인한 사용자가 개별적으로 처리해야 하는 주간 업무, 일상적인 태스크, 단발성 액션 아이템 등을 관리하는 개인 생산성 관리 센터입니다. 중요도 별 분류, 시간 알람 설정, 반복 주기 설계 및 예산 정보 기록을 지원합니다.

---

## 2. 화면 구성 및 UI 레이블 설명

### 2.1 상단 컨트롤
* **[새 할 일] 버튼 (청색)**: 
  * 역할: 상세한 메타 정보와 하위 테스크를 동반한 새로운 일정을 등록하는 폼 모달을 엽니다.
  * 연동 모달: `Create Task Modal`

### 2.2 메인 툴바 필터 및 제어 영역
* **검색 창**: 할 일 제목 및 본문 설명 텍스트 실시간 필터링.
* **상태 필터**: `전체`, `할 일` (todo), `진행 중` (in_progress), `완료` (completed) 조건 필터.
* **중요도 필터**: `전체`, `긴급` (urgent), `높음` (high), `보통` (medium), `낮음` (low) 조건 필터.
* **뷰 모드 토글**:
  * **리스트 뷰**: 스프레드시트 형태 그리드 뷰 (`MondayBoard` 연동).
  * **카드 뷰**: 중요도 카드 타일 형태의 그리드 뷰 (`TaskCardView` 연동).

### 2.3 할 일 등록 모달 (Create Task Modal)
* **할 일 제목** (필수): 수행할 작업 명칭.
* **상세 설명 (Rich Memo)**: 
  * 마크다운 형식의 제목(Header), 리스트 목록, 테이블 도구 등을 사용하여 서식이 있는 업무 메모를 작성합니다 (`RichMemoEditor` 에디터 내장).
* **중요도 (Priority)**: 작업의 우선순위를 선택합니다 (긴급/높음/보통/낮음).
* **기한 (due date)**: 마감일 및 구체적 시간을 입력합니다 (예: `2026-06-19T14:00`).
* **예산 (budget)**: 태스크 수행에 소요되는 예산 금액 (단위: USD).
* **알람 (alarmEnabled)**: 
  * 클릭 시 **[설정됨] (노란색 종 아이콘)** 및 **[꺼짐] (회색 종 아이콘)** 상태가 토글되며, 기한 도래 시 시스템 푸시 알림을 트리거합니다.
* **반복 주기 (recurring)**: 안 함, 매일, 매주 중 반복 형태를 지정합니다.
* **세부 항목 및 파일 링크**:
  * 할 일 하위의 세부 작업 내용과 함께, 업무 관련 문서/파일이 저장된 클라우드 폴더 주소(Google Drive 등 URL)를 [링크] 형태로 동시 추가 보관할 수 있습니다.

---

### 2.4 상세 정보 및 하위 태스크 제어 패널 (TaskDetailPanel)
할 일 목록의 행을 클릭하면 우측에서 열리는 상세 보조 보드입니다.
* 마감 기한 수정, 중요도 변경 및 완료 처리 체크박스를 즉시 지원합니다.
* 본 할 일 하위의 **세부 세부 태스크 추가 기능 (`onCreateSubtask`)**을 제공하여, 메인 일정을 쪼개어 단계별 완료 상태로 체킹할 수 있습니다.

---

## 3. 핵심 비즈니스 로직 및 제약 사항
* **MondayBoard 인라인 신속 등록**:
  리스트 뷰(`MondayBoard`) 활성화 상태에서는 신규 모달 창을 켜지 않고도, 각 그룹(할 일 / 완료) 하단에 마련된 빈 텍스트 입력 셀을 클릭하여 **제목만 입력한 뒤 [추가] (엔터키 또는 버튼) 버튼을 눌러 작업을 빠르게 즉시 등록**할 수 있습니다.
* **사용자 격리 원칙**:
  개인 태스크는 협업 채널과 다르게 다른 사람에게 공유되지 않으며, 데이터베이스 쿼리 작동 시 로그인한 계정의 고유 식별자(`ownerUid`)를 조건으로 강제 검색(User Isolation)되어 유출을 차단합니다.
