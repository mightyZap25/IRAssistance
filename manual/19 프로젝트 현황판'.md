# 통합 운영 관리 매뉴얼 (ProjectDashboardPage.md)

## 1. 메뉴 개요 및 경로
* **메뉴 경로**: 프로젝트 관리 > 통합 운영 관리
* **화면 역할**: 전사 프로젝트들의 현재 진척 단계, 지연 리스크, 미결 이슈 수치 및 긴급 대응 리스크를 모니터링하여 개발 공정상의 위험 요소를 선제적으로 진단하고 조치하는 허브 대시보드입니다.

---

## 2. 화면 구성 및 UI 레이블 설명

### 2.1 상단 헤더 및 컨트롤
* **타이틀**: 통합 운영 관리 / `프로젝트 진척도와 리스크(이슈) 현황을 한눈에 통합 관리합니다.`
* **[데모 샘플 생성] 버튼 (청색 테두리)**: 
  * 역할: 시스템 평가 및 동작 검증을 위해 가상의 데모용 샘플 프로젝트 1개, 관련 이슈 2개, 개인 할 일(Task) 1개를 데이터베이스에 원천 생성합니다.

### 2.2 실시간 통계 요약 카드 (Stat Cards)
* **활성 프로젝트**: 현재 완료 단계('양산이관')가 아닌 활발히 진행 중인 프로젝트 수 / 전체 프로젝트 수.
* **일정 지연 프로젝트**: 공정 일정상 마감 기한이 경과하였으나 완료되지 않은 프로젝트 수. 지연 프로젝트가 1개 이상일 경우 **붉은색 경고 테두리**가 켜집니다.
* **미결 이슈 (Active)**: 전체 발생한 이슈 중 해결('done') 단계를 제외한 접수/진행 중인 이슈 수 / 누적 전체 이슈 수.
* **중점 관리 (긴급/높음)**: 미결 이슈 중 우선순위가 '긴급(urgent)' 또는 '높음(high)'으로 즉각 조치가 필요한 이슈 수. 존재 시 **붉은색 경고 테두리**가 켜집니다.

### 2.3 다차원 리스크 분포 차트 (클릭 시 세부 모달 제공)
1. **개발 공정별 분포**: 
  * 역할: 6대 개발 공정(개발 기획, 개발, 개발 PP, QA Test, 생산 PP, 양산이관)별로 귀속된 프로젝트 개수를 시각화합니다.
  * 인터랙션: 각 공정별 카드를 클릭하면 해당 단계의 구체적인 프로젝트 목록을 담은 상세 팝업이 노출됩니다.
2. **이슈 우선순위 현황**:
  * 역할: 현재 조치 중인 미결 이슈들을 우선순위(긴급, 높음, 보통, 낮음)에 따라 집계합니다.
  * 인터랙션: 각 순위 카드를 클릭하면 해당하는 미결 이슈들의 목록 팝업이 열립니다.
3. **긴급 조치 필요 이슈 (Warning Card)**:
  * 역할: 긴급 및 높음 등급의 미결 이슈 총수를 나타내며, 시각적 바운싱(Bouncing) 애니메이션 아이콘이 포함되어 리스크를 즉각 인지할 수 있도록 유도합니다.
  * 인터랙션: 카드 클릭 시 조치 대기 중인 긴급 이슈 상세 목록 팝업이 열립니다.

### 2.4 상세 내역 오버레이 모달 (Detailed Overlay Modal)
* 각 리스크 및 공정 분포 클릭 시 활성화되는 팝업창입니다.
* **목록 행 클릭 시**: 해당 도메인 상세 페이지로 즉시 이동합니다.
  * 프로젝트 명 클릭 시 ➔ [전사 개발 프로젝트 관리] 페이지로 이동.
  * 이슈 제목 클릭 시 ➔ [이슈 트레커] 페이지로 이동.

### 2.5 전사 프로젝트 진척 및 리스크 리포트 테이블 (하단 영역)
등록된 전체 프로젝트의 종합 상태 리포트 그리드입니다.

| 컬럼 레이블 | 데이터 필드 | 표시 방식 및 리스크 판정 조건 |
| :--- | :--- | :--- |
| **프로젝트** | `name`, `code` | 프로젝트 명칭 및 고유 코드(Mono Font). |
| **공정 단계** | `currentStage` | 현재 귀속된 공정 단계에 매핑되는 고유 식별 색상의 둥근 배지 형태. |
| **진척도** | `progress` | 수평 프로그레스 바 차트 및 진행률 백분율(%) 표기. |
| **이슈 현황** | `issues` | 프로젝트별 미결 이슈 건수와 전체 누적 이슈 건수를 대조 표기 (`OPEN: {미결} | TOTAL: {전체}`). 미결 이슈가 있을 시 붉은색 텍스트로 강조됩니다. |
| **리스크** | `risk` | 미결 이슈가 **3건을 초과**하거나, 공정 일정이 **지연**된 경우 빨간색 경고 아이콘과 함께 **[일정지연]** 혹은 **[이슈과다]** 메시지가 켜집니다. 안전한 프로젝트는 초록색 체크마크와 함께 **[안정적]** 배지가 켜집니다. |

## 3. 핵심 비즈니스 로직 및 제약 사항
* **동적 일정 지연 감지 로직**:
  현재 진척 중인 공정 단계(`currentStage`)에 수립된 스케줄 마감일(`end`)이 오늘 날짜보다 과거이면서, 해당 단계의 스케줄 상태(`status`)가 `completed`가 아닌 프로젝트를 전수 조사하여 지연 카운트에 반영합니다.
* **샘플 데이터 시드 배포**:
  [데모 샘플 생성] 시 실행되는 트랜잭션은 Firestore `projects`, `issues`, `personal_tasks` 세 개의 컬렉션에 유기적인 일방 연결값(Project ID 등)을 동적으로 생성하여 레코드를 추가합니다.
