# 품질 공정 통합 관리 (QA) 매뉴얼 (QualityProcessPage.md)

## 1. 메뉴 개요 및 경로
* **메뉴 경로**: 품질 관리 > 품질 공정 통합 관리 (또는 구버전 QA 모니터)
* **화면 역할**: `quality_inspections` 마스터 내역을 조회하는 단순 모니터링 페이지입니다. 수입, 공정, 출하 등 전 영역의 검사 의뢰 접수 현황과 검사 결과 상태를 통합 그리드로 신속하게 추적합니다. (상세 입력 및 성적서 처리 등의 기능은 본래 [품질 공정 및 모니터링] 메뉴에서 다루며, 본 페이지는 조회 전용 모니터로 쓰입니다.)

---

## 2. 화면 구성 및 UI 레이블 설명

### 2.1 상단 필터 탭
* **전체 검사 (ALL)**: 수입, 중간, 출하 등 상태에 무관하게 모든 의뢰 건을 보여줍니다.
* **출하 검사 (FINAL)**: 제조(Production)가 끝나고 출하를 위해 최종 검사가 필요한 내역을 필터링합니다.
* **공정 검사 (PROCESS)**: 제조 도중에 공정 내 검사(In-Process)로 요청된 건들을 필터링합니다.

### 2.2 통합 검사 그리드 (MasterDataGrid)
* 검색창을 통해 검사 ID 및 품목명 기준으로 결과를 즉각 필터링할 수 있습니다.

| 컬럼 레이블 | 데이터 필드 | 표시 형식 및 기능 설명 |
| :--- | :--- | :--- |
| **검사 ID** | `ID` | 시스템이 발급한 검사 건의 고유 키 (작은 모노 폰트로 가시성 제공). |
| **유형** | `Type` | 검사 종류 분류 표시.<br> - `INCOMING`: **수입검사** (트럭 아이콘, 파란색)<br> - `PROCESS`: **공정검사** (공장 아이콘, 황색)<br> - `FINAL`: **출하검사** (패키지 아이콘, 초록색) |
| **품목명** | `PartName` | 해당 부품명 표기. 하단에 연계 정보인 참조 ID(`REF: {RefID}`)가 작은 폰트로 함께 출력되어 원천 거래와의 추적성을 지원합니다. |
| **요청수량** | `Qty` | 검사를 의뢰한 수량. |
| **요청일시** | `RequestedAt` | 검사 요청이 접수된 일자와 시각. |
| **진행 상태** | `Status` | 현재의 검사 단계 표시.<br> - `WAITING`: **[검사대기]** (회색 테두리 배지)<br> - `IN_PROGRESS`: **[검사중]** (보라색 테두리 배지)<br> - `PASS`: **[합격(PASS)]** (초록색 배지)<br> - `FAIL`: **[불합격(FAIL)]** (적색 배지) |

## 3. 핵심 비즈니스 로직 및 제약 사항
* **일회성 데이터 조회**: 본 페이지는 리소스 절약을 위해 실시간 리스너(`onSnapshot`)를 연결하지 않고 페이지 초기 진입 시점에 단발성(`getDocs`)으로 데이터를 호출하여 렌더링합니다. 최신 정보가 필요할 경우 페이지 새로고침이 필요합니다.
* **추적 코드 연계**: 각 검사는 `RefID` (발주번호 또는 생산의뢰번호)를 갖고 있어 원천 데이터가 어디서 이관되었는지 추적할 수 있는 참조 관계를 맺고 있습니다.
