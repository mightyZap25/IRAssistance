# 엔터프라이즈 캔버스 대시보드 (Dashboard) 사용자 매뉴얼

엔터프라이즈 캔버스 대시보드(Enterprise Canvas)는 리액트 그리드 레이아웃(React Grid Layout) 기술을 기반으로 설계되어, 사용자가 본인의 주 업무에 맞춰 위젯 배치, 크기 조절, 스타일 테마 및 데이터 소스 필터링 조건을 직접 맞춤형으로 자유롭게 꾸미고 관리할 수 있는 맞춤형 종합 ERP 상황판입니다.

---

## 1. 개요 및 권한 정책

*   **메뉴 경로**: 사이드바 ➡️ **Dashboard (대시보드 / 메인)**
*   **주요 역할**: 임직원 개인별 맞춤 위젯(BOM, 재고, 근태, 할 일 등) 배치 및 크기 조절, 위젯 개별 스타일(배경색, 테두리, 투명도) 제어, 데이터 소스 필터링 기반 사용자 정의 리스트 바인딩, 개인 맞춤 레이아웃 영구 보존.
*   **권한 요구사항**:
    *   **전사 임직원 (User/Manager/Admin)**: 직급 및 직책에 관계없이 전사 임직원 누구나 개별적으로 본인 계정에 할당된 고유 대시보드를 자유롭게 꾸미고 독립 저장할 수 있습니다.

---

## 2. 화면 구성 및 위젯 카탈로그 정의

### 2.1 상단 대시보드 편집 툴바
*   **대시보드 꾸미기**: 대시보드를 드래그하여 배치하고 위젯을 추가할 수 있는 디자인 편집 모드를 활성화합니다.
*   **배경색 지정 (Palette)**: 대시보드 캔버스 전체의 기본 배경색(Background Color)을 컬러 피커를 통해 동적으로 설정합니다.
*   **위젯 추가 (Plus)**: 우측에 위젯 카탈로그 사이드바를 노출시켜 원하는 기능의 위젯을 즉시 추가할 수 있게 돕습니다.
*   **저장 완료 (Check)**: 사용자가 가공한 위젯 좌표(X, Y, W, H) 및 커스텀 스타일 설정을 데이터베이스에 동기화 저장하고 일반 뷰어 모드로 복귀합니다.

### 2.2 위젯 종류 및 기본 규격 정의
| 위젯 ID | 위젯 명칭 | 기본 규격 (W x H) | 설명 |
| :--- | :--- | :--- | :--- |

| **approval** | **결재 대기 문서** | `4 x 8` | 자신이 결재해야 하는 전자결재 상신 목록 검토 및 승인/반려 바로가기 |

## 3. 세부 제어 기능 및 속성 커스터마이징

### 3.1 드래그 앤 드롭 및 크기 재조정 (RGL 제어)
*   **위젯 이동**: 편집 모드 활성화 시 각 위젯 상단 영역의 핸들(`drag-handle`)을 잡고 마우스로 끌어 20열 그리드 캔버스 상의 원하는 빈 곳으로 자유롭게 위젯을 이동시킬 수 있습니다.
*   **크기 조정 (Resize)**: 위젯 테두리 우측 하단 모서리의 크기 조절 앵커를 잡아당겨 가로 및 세로의 높낮이를 동적으로 확장/축소할 수 있습니다. 배치 시 충돌 방지 알고리즘이 적용되어 기존 위젯들이 자연스럽게 밀려나거나 흐릅니다.

### 3.2 위젯 스타일 속성 설정 (우측 사이드바)
*   편집 모드에서 위젯 카드를 클릭 시 우측에 개별 스타일 속성 설정 패널이 노출됩니다.
    *   **배경색 및 투명도**: 위젯 카드의 배경을 컬러 피커로 지정하고 투명도 슬라이더(0% ➡️ 100%)를 조절하여 대시보드 배경과 자연스럽게 오버레이되도록 처리합니다.
    *   **테두리 색상 및 테두리 투명도**: 카드 외곽 경계선의 두께 느낌을 주는 보더 컬러 및 선의 불투명도를 설정합니다.

### 3.3 텍스트 메모 위젯 설정 (Text Customize)
*   일반 메모지와 다르게 메모 제목 입력 숨김 기능 및 아래의 타이포그래피 사양 변경을 실시간 반영합니다.
    *   **글꼴 선택**: Pretendard, Gmarket Sans, Monospace, Serif, Sans-Serif 지정.
    *   **글자 크기**: 픽셀(px) 단위 수동 입력 지정.
    *   **서식 및 정렬**: 볼드체 토글, 가로 정렬(좌측 / 중앙 / 우측) 버튼식 제어.
    *   **폰트 컬러**: 텍스트의 글자 색상 피커 제어.

### 3.4 사용자 정의 리스트 위젯 설정 (Dynamic List Customize)
사용자가 원하는 데이터 테이블을 ERP 원천 데이터에서 실시간 쿼리하여 리스트 형태로 조망합니다.
*   **위젯 타이틀**: 리스트 박스 상단에 노출될 별칭 제목 기입.
*   **데이터 소스 지정**: 부품 대장(`parts`), BOM(`boms`), 설계변경(`ECOs`), 발주서(`purchaseOrders`), 생산의뢰(`productionRequests`) 중 바인딩할 원천 컬렉션을 선택합니다.
*   **조건부 필터 빌더 (Filter Builder)**: [필터 추가] 버튼을 통해 복수의 필터링 룰을 누적 설정합니다.
    *   **필드명 입력**: 비교 대상 필드 명칭 기재 (예: `Lifecycle` 또는 `Category`).
    *   **비교값 입력**: 필터링 대상 문자열이나 상태값 기재 (예: `Obsolete` 또는 `Active`).
    *   이를 통해 '단종된 부품 목록 위젯', '긴급 생산의뢰 위젯' 등 맞춤형 특수 위젯을 코딩 없이 즉석 생성 가능합니다.

## 4. 데이터 연동 및 DB 매핑 정보

### 4.1 Firestore DB 및 레이아웃 관리 서비스
*   대시보드 위젯의 좌표 정보와 사용자가 맞춤화한 커스텀 스타일 정보는 Firestore 내의 `users` 또는 지정된 레이아웃 관리 컬렉션에 유저 고유 ID(`UID`) 명칭의 문서로 연계 보존됩니다.
*   **레이아웃 관련 서비스 함수 ([userService.js](file:///D:/workspace/IR_Assistant/src/services/userService.js))**:
    *   `getUserDashboardLayout(uid)`: Firestore에서 로그인된 사원의 대시보드 레이아웃 배열(`layout`) 및 배경색/폰트 스타일 속성(`style`)을 가져옵니다. 저장 데이터가 없는 초기 로그인 유저인 경우 사전 정의된 기본 규격 세트(`DEFAULT_LAYOUT`)를 로드하여 화면에 바인딩합니다.
    *   `saveUserDashboardLayout(uid, config)`: 편집된 레이아웃 배열과 설정값을 사용자 고유 문서 필드에 단일 트랜잭션으로 저장합니다.
