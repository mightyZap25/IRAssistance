# 파일 및 드라이브 연동 (Files) 사용자 매뉴얼

파일 및 드라이브 연동은 클라우드 스토리지(Google Drive REST API)와 로컬 Firestore 데이터베이스를 결합하여, 사내 표준 업무 템플릿(생산계획, 품질 NCR, 발주의뢰서 등)을 복제/기안하고, 전용 공유 폴더 내의 부서별 파일들을 실시간 브라우징 및 조회/편집할 수 있는 스마트 파일 관리 센터입니다.

---

## 1. 개요 및 권한 정책

*   **메뉴 경로**: 사이드바 ➡️ **공통 / 협업** ➡️ **Files (파일 관리)**
*   **주요 역할**: 구글 드라이브 실시간 OAuth 권한 획득, 연동 공유 폴더 브라우징, 사내 문서/시트 템플릿 복제 생성 및 보관, ERP 내부 구글 오피스 Iframe 무중단 편집.
*   **권한 요구사항**:
    *   **전사 임직원 (User/Manager/Admin)**: 본인 회사 계정의 구글 연동 완료 시, 공유 폴더의 쓰기/읽기 권한에 맞춰 자유롭게 문서를 미리보고 신규 문서 작성을 진행할 수 있습니다.

---

## 2. 화면 구성 및 레이블 정의

### 2.1 상단 헤더 및 컨트롤
*   **신규 문서 작성 (템플릿) 버튼**: 업무 양식(생산보고서, 품질NCR, 자재입출고의뢰서 등)을 로컬 또는 구글 클라우드 드라이브로 복제 생성하는 팝업 폼을 활성화합니다.

### 2.2 구글 드라이브 탐색기 (Google Drive Explorer)
*   **폴더 브레드크럼 (Breadcrumb)**: 최상위 연동 폴더부터 현재 진입한 하위 폴더까지의 경로 히스토리를 가로로 나열하며, 특정 경로명을 클릭해 상위 디렉토리로 즉각 점프 이동합니다.
*   **상위 폴더 바로가기**: 클릭 시 바로 직전 부모 디렉토리로 1단계 뒤로 가기를 수행합니다.
*   **연동 경고 배너**: OAuth 엑세스 토큰이 만료되었거나 연동 승인이 끊긴 경우 노출되는 안내창으로, 우측 상단 인증 버튼 클릭을 통해 세션을 갱신할 수 있도록 가이드합니다.
*   **파일 목록 테이블 레이블**:
    *   **이름**: 파일명 및 디렉토리 명칭. 확장자 및 MIME-Type에 따라 폴더(`Folder`), 스프레드시트(`FileSpreadsheet`), 워드문서(`FileText`) 아이콘으로 자동 분기 시각화됩니다.
    *   **소유자**: 구글 드라이브 상의 원본 파일 기안자 이름.
    *   **최종 수정일**: 드라이브 상에서 파일 변경이 일어난 최종 수정 시간.
    *   **크기**: KB 단위 파일 크기 (폴더는 `-` 처리).
    *   **동작 (미리보기/눈 모양 아이콘)**: 클릭 시 본 포털 내부의 편집 뷰어 창을 엽니다 (더블클릭 동작과 동일).

## 3. 세부 기능 및 API 연동 로직

### 3.1 구글 계정 OAuth 연동 및 장애 폴백
*   **실시간 토큰 갱신**: 사용자가 파일 관리 메뉴에 접속하거나 리스트를 탐색할 때 `ensureValidToken()` 모듈이 구동되어 토큰 만료 여부를 점검합니다. 만료 시 사용자 인터랙티브 팝업창(`signInWithPopup`)을 띄워 백그라운드에서 보안 승인을 갱신합니다.
*   **경고 알림 및 데모 폴백**: 구글 계정 로그인이 미완료된 오프라인 상태이거나 연동 장애가 발생하면, 시스템 알림판(`notifications` 컬렉션)에 [구글 Workspace 연동 실패] 중복 차단 알림을 즉시 적재하고, 화면상에는 고품질 가상 드라이브 트리 구조(`INITIAL_DRIVE_DATA`)를 가상 바인딩해 가동 중단(Downtime)을 예방합니다.

### 3.2 문서 미리보기 및 Iframe 직접 편집 (File Viewer)
*   리스트 내 파일 행을 클릭하면 최대 스크린 너비 크기의 파일 뷰어 모달이 열립니다.
*   **구글 오피스 임베딩**: 구글 문서나 스프레드시트 포맷 파일의 경우, 구글의 공식 에디터 주소를 파싱하여 `edit?rm=minimal` 형태의 minimal 임베디드 모드로 프레임을 호출합니다. 사용자는 **ERP 포털 창을 떠나지 않고 Iframe 내부에서 실시간으로 글자를 쓰고 셀을 수정**할 수 있으며, 이 변경점은 구글 드라이브 원본 파일에 즉각 자동 저장됩니다.
*   **로컬 문서 미리보기**: 파이어베이스에 보관된 로컬 문서의 경우 줄바꿈이 적용된 텍스트 뷰로 노출되며, 시트 형식은 CSV 파서가 테이블 그리드로 가공 렌더링합니다.

### 3.3 템플릿 복제 생성 (Create File Modal)
*   **로컬 저장**: `workspace_files` 컬렉션에 사용자가 작성한 문서를 신규 등록합니다.
*   **구글 드라이브 복제 (Drive Copy Process)**:
    1.  구글 드라이브 내에 보관된 `template` 폴더의 ID를 검색하고, 해당 폴더 안의 업무 양식 파일(품질 NCR 템플릿, 자재의뢰서 등) 리스트를 스캔해 로드합니다.
    2.  사용자가 템플릿 양식과 대상 폴더를 선택하고 파일명을 지정하여 등록을 누릅니다.
    3.  Google Drive API의 파일 복제 복사본 생성 엔드포인트(`drive.files.copy`)에 타겟 폴더 ID를 지정해 복제본을 저장하고 브라우저 목록을 갱신합니다.

## 4. 데이터 연동 및 DB 매핑 정보

### 4.1 데이터 저장 구조 및 API 연동 매핑
*   **로컬 파일 보관 DB**:
    *   Firestore 내 `workspace_files` 컬렉션을 참조합니다.
    *   **컬렉션 구조**:
        *   `name` (String): 파일 이름 (선택 양식에 따라 `.docx` / `.xlsx` 자동 추가).
        *   `type` (String): 문서 형태 (`doc` / `sheet`).
        *   `category` (String): 저장 경로 분류 (로컬 보관 시 `local`).
        *   `content` (String): CSV 구분자 문자열 또는 일반 텍스트 데이터.
        *   `size` (String): 계산된 파일 용량 크기.
        *   `owner` (String): 작성 임직원 명칭.
        *   `createdAt` (Timestamp): 생성일자.
*   **Google Drive API 엔드포인트**:
    *   공유 폴더 내 목록 탐색: `GET https://www.googleapis.com/drive/v3/files?q='{folder_id}'+in+parents+and+trashed=false&fields=files(...)`
    *   템플릿 파일 복사 생성: `POST https://www.googleapis.com/drive/v3/files/{template_file_id}/copy` (요청 Body 내 `parents`에 생성 타겟 폴더 ID 배열 매핑)
