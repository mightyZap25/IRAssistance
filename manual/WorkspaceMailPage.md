# 통합 메일 센터 (Mail) 사용자 매뉴얼

통합 메일 센터는 Google Workspace(Gmail API) 및 외부 메일 서비스와 실시간 연동하여 전사적인 내/외 업무 커뮤니케이션을 한곳에서 관리할 수 있는 통합 오피스 허브입니다.

---

## 1. 개요 및 권한 정책

*   **메뉴 경로**: 사이드바 ➡️ **공통 / 협업** ➡️ **Mail (메일)**
*   **주요 역할**: 실시간 메일 수신 및 조회, 메일 작성 및 발송, 답장/전달, 중요 표시 설정, 외부 메일 계정(IMAP) 연동 관리.
*   **권한 요구사항**:
    *   **전사 임직원 (User/Manager/Admin)**: 본인 계정의 구글 연동 권한을 활용하여 누구나 동일하게 본인 메일 조회, 발신, 외부 메일함 연동 기능을 사용할 수 있습니다.

---

## 2. 화면 구성 및 레이블 정의

### 2.1 상단 및 사이드바 컨트롤 영역
*   **외부 메일 연동 버튼**: Outlook/MS 365, Google Gmail 및 기타 사내 IMAP 메일 서버를 연동할 수 있는 팝업 모달을 띄웁니다.
*   **새 메일 작성 버튼**: 새 메일을 발송할 수 있는 작성 창(모달)을 엽니다.
*   **검색창**: 메일 리스트에서 보낸 사람 이름, 제목, 본문 텍스트 내 키워드를 실시간으로 검색 및 필터링합니다.
*   **폴더 네비게이션**:
    *   `inbox` (수신함): 읽지 않은 메일 개수가 뱃지로 노출됩니다.
    *   `starred` (중요 메일): 사용자가 중요 표시(별표)를 설정한 메일 목록입니다.
    *   `sent` (보낸 메일함): 사용자가 발송 완료한 메일 리스트입니다.
    *   `drafts` (임시 보관함): 작성 중 저장된 메일 리스트입니다.
    *   `archive` (아카이브): 보관 처리된 메일함입니다.
    *   `trash` (휴지통): 삭제된 메일함입니다.
*   **분류 태그 리스트**: `업무보고`(blue), `견적`(emerald), `해외`(violet), `긴급`(rose)의 고유 컬러 태그를 클릭하여 메일을 필터링합니다.

### 2.2 메일 리스트 컴포넌트 레이블
| 레이블명 | 필드 키 | 설명 |
| :--- | :--- | :--- |
| **별표 토글** | `isStarred` | 클릭 시 중요 메일함(`starred`)으로 즉시 동기화되는 별표 활성 플래그 |
| **보낸이 이니셜** | `sender[0]` | 발신자 이름의 첫 글자를 아바타 형태로 시각화 |
| **보낸 사람** | `sender` | 발신자의 명칭 또는 한글 이름 |
| **보낸이 이메일** | `email` | 발신자의 이메일 주소 (마우스 오버 시 표시) |
| **수신 일시** | `date` | 메일이 들어온 날짜 또는 시간 |
| **메일 제목** | `subject` | 수신된 메일의 제목 (제목이 없는 경우 `(제목 없음)` 표시) |
| **본문 스니펫** | `content` | 본문 내용의 앞 부분을 미리 보여주는 1줄 요약 텍스트 |
| **첨부파일 유무** | `hasAttachment` | 클립 아이콘으로 메일 내 첨부파일 존재 여부 시각화 |
| **태그** | `tags` | 메일에 설정된 분류용 뱃지 목록 |

## 3. 세부 기능 및 모달 액션

### 3.1 메일 열람 및 상세 정보 뷰어 (상세 우측 패널)
리스트에서 개별 메일을 클릭하면 우측에서 상세 정보창이 슬라이딩 아웃됩니다.
*   **아카이브 / 삭제 / 스팸신고 버튼**: 메일의 소속 폴더를 휴지통이나 아카이브로 이동 변경시킵니다.
*   **별표 토글**: 실시간 중요 표시 플래그 전환.
*   **첨부파일 다운로드**: 첨부된 문서(예: PDF)의 크기(Size)와 이름을 명시하고 바로가기 버튼(`ExternalLink`)을 통해 조회/다운로드를 지원합니다.
*   **답장하기(Reply)**: 해당 발신자 수신처와 제목(`Re: ...`) 및 원본 본문 템플릿이 자동으로 입력된 상태로 새 메일 창을 활성화합니다.
*   **전달하기(Forward)**: 메일 본문 내용을 그대로 유지한 채 다른 수신자에게 포워딩하는 폼을 엽니다.

### 3.2 새 메시지 작성 (Compose Modal)
*   **받는 사람 (To)**: 필수 항목. 이메일 정규식 유효성 검사가 작동합니다.
*   **제목 (Subject)**: 필수 항목.
*   **본문 (Content)**: 메일의 메인 메시지를 입력하는 멀티라인 텍스트 영역입니다.
*   **보내기 버튼**: 실시간 Google API를 통해 메일을 암호화 발송하고 모달을 닫습니다.

## 4. 데이터 연동 및 DB 매핑 정보

### 4.1 클라이언트 스토리지 및 API 매핑
*   **구글 OAuth2 연동**: 브라우저 `localStorage`에서 아래 토큰 정보를 실시간 참조하여 Google API 호출을 수행합니다.
    *   `google_access_token`: API 인증에 사용되는 OAuth 엑세스 토큰.
    *   `google_access_token_expires_at`: 토큰의 만료 타임스탬프 (만료 시 팝업 갱신을 통해 토큰 재발행).
*   **호출 API**:
    *   메일 목록 로드: `GET https://gmail.googleapis.com/gmail/v1/users/me/messages?maxResults=15`
    *   메일 세부 내용 로드: `GET https://gmail.googleapis.com/gmail/v1/users/me/messages/{message_id}` (MIME-Type 파싱 후 헤더 정보 및 Snippet 추출)
    *   메일 전송: `POST https://gmail.googleapis.com/gmail/v1/users/me/messages/send` (Base64 URL-safe 인코딩 데이터 전송)
*   **연동 실패 폴백**: 네트워크 오프라인 또는 API 토큰이 만료되어 갱신에 실패한 경우, 시스템은 고품질의 데모용 `mockData` 배열을 화면에 바인딩하여 무중단 사용자 경험을 유지합니다.
