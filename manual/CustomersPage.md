# 고객사 관리 (Customers) 사용자 매뉴얼

고객사 관리 메뉴는 매출의 근간이 되는 고객사 정보, 다중 담당자 리스트를 가로형으로 조밀하게 입력/관리하고 견적서, 세금계산서 및 이메일 소통 내역을 통합 타임라인으로 조회하는 CRM 연동 센터입니다.

---

## 1. 개요 및 권한 정책

*   **메뉴 경로**: 사이드바 ➡️ **ERP** ➡️ **Customers (고객사 관리)**
*   **주요 역할**: 고객사 마스터 관리, 다중 연락처 매핑, 매출 집계, 거래 통합 히스토리 트래킹.
*   **권한 요구사항**:
    *   **일반 사원 (User/Guest)**: 고객사 목록 및 연락처 정보 조회, 납품 이력 및 통합 타임라인 이력 조회.
    *   **영업/관리자 (Manager/Admin)**: 고객사 등록 및 수정, 단가/결제 조건 등록, 고객사 삭제.

---

## 2. 고객사 리스트 화면 구성

### 2.1 리스트 및 카드 그리드 기능
*   **통합 검색**: 고객사명, 담당자명으로 검색 필터링을 지원합니다.
*   **뷰 모드 전환**:
    *   **테이블 뷰(List View)**: 국내/해외 구분 뱃지, 이메일 링크를 포함한 표 구조.
    *   **카드 뷰(Card View)**: 고객사의 상세 대표 연락처, 고유 ID(UUID), 매출 트랙 분석 링크(View Insights)를 한눈에 볼 수 있는 블록 구조.
*   **액션 버튼**: 각 카드 및 테이블 행 우측에 수정(Pencil) 및 삭제(Trash) 버튼이 노출됩니다.

### 2.2 리스트 컬럼 및 레이블 정의
| 레이블명 | 필드 키 | 설명 |
| :--- | :--- | :--- |
| **고객사명** | `Name` | 기업체 정식 상호명 |
| **구분** | `Category` | 국내(Domestic) / 해외(Overseas) / 유통사(Distributor) 구분 |
| **담당자** | `ContactPerson` | 대표 주담당자의 이름 |
| **이메일** | `Email` | 주담당자 대표 이메일 |
| **전화번호** | `Phone` | 대표 사무실 또는 주담당자 연락처 |
| **주소** | `Address` | 본사 및 납품지 주소 정보 (리스트 기본 숨김, 필요시 토글) |

## 3. 고객사 정보 & 영업 통합 관리 (우측 상세창)

선택된 고객사를 클릭하면 [CustomerDetailPanel.jsx](file:///D:/workspace/IR_Assistant/src/components/CustomerDetailPanel.jsx) 컴포넌트가 활성화됩니다.

### 3.1 기본 정보 (info) 탭
고객사 마스터의 핵심 정보 및 연락처 목록이 가로 정렬로 조밀하게 정렬되어 한눈에 파악할 수 있습니다.
*   **대표 주소**: 회사 정식 소재지 주소.
*   **다중 연락처 목록 (Contacts)**:
    *   **가로 정렬 정보**: `이름`, `직급`, `전화번호`, `이메일` 정보가 한 라인 단위로 표기되며 다중 등록(여러 담당자)을 완벽하게 지원합니다.
*   **사업자 등록 번호**: 세금계산서 발행을 위한 국세청 사업자 코드.
*   **결제 조건**: 익월 말 결제, 선금 지급 등 거래 수납 조건.
*   **총 누적 매출**: 해당 고객사명으로 완료된 전체 거래 총 합계액.
*   **고객 상태**: 거래 활성화 여부 (`Active Partner`).

### 3.2 납품 완제품 (products) 탭
*   해당 고객사를 납품처로 지정하여 출하 완료(`PLACEMENT_COMPLETE`)된 생산 의뢰 완제품 이력이 출력됩니다.
*   납품 일자, 완제품 품번 및 품명, 실제 납품 수량을 일목요연하게 표시합니다.

### 3.3 통합 이력 (history) 탭
시간 순서대로 정렬되는 전사 통합 타임라인입니다. 각 도메인별로 폰트와 배경 색상이 다르게 표현되어 식별성이 극대화되어 있습니다.
*   **납품 완료 내역 (DELIVERY)**:
    *   **표시**: 녹색 계열 텍스트 / 아이콘.
    *   **내용**: "제품 입고 배치 완료: IRP-XXX / Qty: X" 등의 실물 인도 정보.
*   **견적서 발행 내역 (QUOTE)**:
    *   **표시**: 주황/황색 계열 텍스트 / 아이콘.
    *   **내용**: 발행된 견적 정보 및 총액 정보 (예: `총 금액: ₩12,500,000`).
*   **세금계산서 내역 (INVOICE)**:
    *   **표시**: 보라/적색 계열 텍스트 / 아이콘.
    *   **내용**: "세금계산서 국세청 전송 완료 (공급가액/세액)" 등의 과세 데이터.
*   **통합 이메일 내역 (EMAIL)**:
    *   **표시**: 남색/회색 계열 텍스트 / 아이콘.
    *   **내용**: 연동된 회사 CS/영업 메일 수발신 타임라인 및 메일 요약 본문 (예: `[수신] 도면 변경 건 문의`).

## 4. 고객사 등록 및 수정 폼 모달

*   **고객사명 (필수)**: 중복 등록 체크 유효성 검사 적용.
*   **구분 셀렉터**: 국내 / 해외 / 유통사로 설정.
*   **다중 연락처 편입**: 폼 작성 시 담당자 성함, 전화번호, 이메일을 각각 입력하여 `Contacts` 배열 내 '주담당자(Primary)' 객체 형태로 자동 바인딩합니다.
*   **주소**: 지번 또는 도로명 주소 입력.
*   데이터 저장 시 PostgreSQL의 `customers` 컬렉션에 이력 로그(`CreatedAt`/`UpdatedAt`)와 함께 영속화됩니다.
