# BOM 관리 (Bill of Materials) 사용자 매뉴얼

BOM 관리 메뉴는 완제품(Product) 및 하위 조립품(Assembly)의 원부자재 계층 구조(Tree Structure)를 구축하고, 총 원가 계산, 사양(Spec) 템플릿 검증, 리비전 비교 및 파생 모델 발의를 수행하는 제조 핵심 시스템입니다.

---

## 1. 개요 및 권한 정책

*   **메뉴 경로**: 사이드바 ➡️ **ERP** ➡️ **BOM (BOM 관리)**
*   **주요 역할**: BOM 트리 구축, 소요량(Quantity) 관리, 파생 모델 발의, 리비전 비교(BOM Diff).
*   **권한 요구사항**:
    *   **일반 사원 (User/Guest)**: 완제품 및 조립품의 BOM 트리 조회, 도면 및 스펙 확인, Where-Used(사용처) 이력 조회.
    *   **설계 엔지니어 (Engineer)**: BOM 트리 구조 편집(자재 추가/삭제/수량수정), 신규 완제품/조립품 BOM 생성, 파생 모델 발의, ECN 변경 결재 기안 생성.
    *   **부서 책임자 (Manager/Admin)**: BOM 신규 리비전 등록 및 기안 최종 승인(Active 전환), 기준 정보 카테고리/시리즈 폴더 편집.

---

## 2. 화면 영역 및 UI 구성

BOM 관리 화면은 크게 좌측의 **BOM 폴더/마스터 브라우저** 영역과 우측의 **BOM 상세 제어 및 트리 뷰** 영역으로 양분됩니다.
![[bom main ui.png]]
### 2.1 좌측 영역: 마스터 브라우저 (BOM Explorer)
*   **카테고리/시리즈 트리**: 카테고리(예: Actuator, Board 등)와 세부 시리즈 폴더가 계층 구조로 나열됩니다.
    *   **카테고리 추가**: 신규 폴더 생성.
    *   **시리즈 추가**: 선택된 카테고리 하위에 서브 시리즈 생성.
*   **마스터 품목 리스트**: 선택된 폴더 내의 완제품(IRP로 시작) 또는 반제품/조립품(IRA로 시작) 마스터 품목이 필터링되어 출력됩니다.
    *   **검색창**: 마스터 부품명 또는 Part ID로 즉시 품목을 검색합니다.
    *   **Lifecycle 뱃지**: 품목 상태(`Draft`, `Active`, `Obsolete`)가 한눈에 구분됩니다.
    *   **단종품 표시 체크박스**: 폐기/단종(`Obsolete`)된 마스터 품목의 조회 여부를 제어합니다.

### 2.2 우측 영역: BOM 상세 제어 및 계층 네비게이션
마스터 품목을 클릭하면 활성화되는 영역입니다.

#### ① 상단 브레드크럼 (Breadcrumb Navigation)
*   BOM 트리의 루트(완제품)부터 클릭하여 드릴다운한 하위 어셈블리 경로(예: `완제품 ➡️ PCB 어셈블리 ➡️ 커넥터 모듈`)를 순서대로 노출합니다.
*   경로상의 조립품명을 클릭하면 즉각 해당 노드를 기준으로 삼는 BOM 구조로 최상위 뷰가 전환(Drill-Down)됩니다.
*   **뒤로가기 버튼**: 이전 상위 어셈블리 뷰로 즉시 복귀합니다.

#### ② 제어 액션 버튼 그룹
*   **편집 모드 / 편집 취소**: BOM 구조를 수정할 수 있는 상태로 UI를 토글합니다. (편집 시 자재 추가, 수량 변경, 노드 삭제 버튼 활성화)
*   **파생 발의**: 현재 선택된 완제품/조립품의 BOM 트리를 복제하여 신규 파생 모델(Derivative BOM) 기안 모드로 진입합니다.
*   **이전 리비전 비교**: 현재 BOM 구조와 직전 승인 리비전의 변경 사항(BOM Diff)을 윈도우 한 창에서 자동 비교하여 다이어그램으로 시각화합니다.
*   **승인 (Confirm)**: `Draft` 상태인 BOM 마스터를 정식 생산 가능 상태(`Active`)로 전환 승인합니다. (Manager 전용)
*   **단종 처리 (Discontinue)**: 해당 마스터 부품을 단종(`Obsolete`) 처리하여 사용 중단합니다.

## 3. BOM 트리(BOM Structure Panel) 편집 기능

[BOMStructurePanel.jsx](file:///D:/workspace/IR_Assistant/src/components/BOMStructurePanel.jsx) 컴포넌트로 구현되어 있습니다.

### 3.1 트리 노드 표시 및 레이블
트리 뷰에서 각 자재는 계층선으로 연결되어 표시됩니다.
*   **Part ID**: 해당 자재 코드.
*   **부품명**: 한글/영문 부품 명칭.
*   **단위 수량 (EA/Unit)**: 상위 부품 1개를 생산할 때 소요되는 자재 개수.
*   **총 소요량 (Total Qty)**: 최상위 제품 생산 수량 대비 전체 소요 수량 자동 계산.
*   **기본 보관 위치**: 자재의 창고 위치 정보.
*   **비고 (Note)**: BOM 관계 정보 내 개별 비고 항목.

### 3.2 편집 모드 액션
*   **수량 수정**: `Quantity` 필드를 직접 수정할 수 있으며, 수정 시 해당 노드에 `Modified` 표시가 활성화됩니다.
*   **순서 변경 (Reorder)**: 드래그 앤 드롭을 지원하는 핸들을 클릭하여 상하 노드 조립 순서를 변경할 수 있습니다.
*   **자재 추가 (Add Child)**:
    *   선택된 조립 노드의 하위에 신규 자재를 편입시킵니다.
    *   부품 DB 검색기를 띄워 Part ID를 지정하고 단위 소요량, 보관 위치, 비고를 기입한 뒤 등록합니다.
    *   편입할 자재가 하위 조립품(IRA)인 경우, 해당 조립품에 속한 하위 트리 구조 전체가 재귀적으로 함께 편입됩니다.
*   **노드 삭제 (Delete Node)**: 
    *   BOM 구조에서 영구 탈락시킬 자재를 삭제 처리합니다. ECN 결재 후 최종 저장 시 DB에서 관계가 제거됩니다.
    *   **단종품 처리 (Discontinue)**: 자재 관계를 유지하되 사용 불가 단종 노드로 표시합니다.

## 4. 핵심 제약 및 연동 로직

### 4.1 Actuator 카테고리 필수 사양 검증 (Validation)
완제품 또는 카테고리 폴더가 **Actuator** 유형에 속하는 경우, 저장 시 다음과 같은 7대 특화 제원(Spec) 입력을 필수화하도록 시스템에 하드코딩된 유효성 검사(`validateActuatorSpecs`)를 통과해야 합니다.
1.  **정격부하**
2.  **속도**
3.  **Stroke**
4.  **최소 입력전압**
5.  **최대 입력전압**
6.  **통신 방식** (기본 템플릿 제공: `PT`)
7.  **프로토콜** (기본 템플릿 제공: `IRPROTOCOL`)

### 4.2 파생 BOM 관계 동기화
*   파생 발의 버튼 클릭 시 원본 BOM의 전체 자재 리스트와 계층 깊이가 100% 복제됩니다.
*   파생된 모델 데이터(Part)에는 `BasePartID`와 `BasePartName` 정보가 함께 저장되어 상호 링크 관계를 형성합니다.

### 4.3 ECN 설계 변경 결재 자동 링크
BOM 구조를 편집한 후 저장할 때, 변경 범위가 중요하여 `ECN` 기안이 필요하다고 선택하면:
1.  현재 작업 중인 BOM 구성과 기존 원본 BOM을 자동으로 비교 분석합니다.
2.  **추가된 자재, 삭제된 자재, 수량이 변동된 자재 리스트**를 상세 항목화하여 ECN 문서 본문에 삽입합니다.
3.  만약 변경 대상 BOM 품번의 **파생 모델들(Derivative BOMs)**이 존재한다면, ECN 결재선 검토 목록에 해당 파생 모델 리스트도 시스템적으로 연계 바인딩시킵니다. (영업 승인 시 함께 진행 검토를 하도록 강제하기 위함)
