# 품질 기준 및 마스터 설정 매뉴얼 (QAConfigPage.md)

## 1. 메뉴 개요 및 경로
* **메뉴 경로**: 품질 관리 > 품질 설정
* **화면 역할**: 수입검사(수급 자재) 대상 부품을 지정하고 세부 검사 규격(공차, 검사 도구, 샘플링 방식 등)을 정의합니다. 또한 공정 전반(수입, 중간, 출하, AS)에서 사용하는 공통 불량 코드 표준 마스터를 관리합니다.

---

## 2. 화면 구성 및 UI 레이블 설명

### 2.1 상단 탭 구성
* **수입검사 품목 설정**: 
  * 역할: 등록된 전체 부품 목록을 그리드로 조회하고 수입검사를 필수로 수행해야 하는 대상을 정의합니다.
  * 배지: 등록된 총 수입검사 대상 품목 수 (`qaParts.length`)가 표시됩니다.
* **불량 코드 마스터**:
  * 역할: 불량 원인 및 결함 유형 마스터 데이터를 신규 등록하고 관리합니다.
  * 배지: 등록된 총 불량 코드 수 (`defectCodes.length`)가 표시됩니다.

---

### 2.2 수입검사 품목 설정 탭 (UI 요소)
부품 그리드 내의 각 행은 부품 정보와 현재 설정 상태를 표시합니다.

| 컬럼 레이블 | 데이터 필드 | 표시 형식 및 기능 설명 |
| :--- | :--- | :--- |
| **Part ID** | `PartID` | 부품의 고유 코드. |
| **부품명** | `Name` | 부품의 한글/영문 명칭. |
| **규격** | `Spec` | 해당 부품의 크기, 정격 등 사양 규격. |
| **검사 설정 상태** | `qaStatus` | `qa_target_parts`에 부품 ID 존재 시 **[검사 대상] (초록색 펄스 점)**, 존재하지 않을 시 **[미설정] (회색 점)**으로 표시됩니다. |
| **관리** | `action` | 클릭 시 **[검사 설정] (톱니바퀴 아이콘)** 버튼이 제공되며, 이를 클릭하여 검사항목과 합격 임계치 등을 설정하는 `QAStandardSetupModal`을 호출합니다. |

---

### 2.3 불량 코드 마스터 탭 (UI 요소)

#### A. 불량 코드 신규 등록 폼
* **불량 분류 (Select Box)**: `수입검사` (Receiving), `중간검사` (Middle), `출하검사` (Shipping), `AS` (As) 중 해당 불량이 주로 발생하는 단계를 선택합니다.
* **불량 코드 (Input)**: 수동으로 고유 코드를 입력합니다. 미입력 상태로 등록할 경우, **[자동 생성 가능]** 기능에 의해 불량명칭 기반 접미사 조합(`DF_{한글/영문명}_{랜덤4자리}`) 형식으로 자동 부여됩니다.
* **불량명 (원인명) (Input)**: 실제 불량 유형칭을 입력합니다 (예: `도금 불량`, `파손/크랙`).
* **[마스터 데이터로 등록하기] 버튼**: 폼에 입력된 내용을 마스터 DB에 최종 저장합니다.

#### B. 불량 코드 마스터 그리드 목록
* **[표준 불량 세트 자동 등록] 버튼 (번개 아이콘)**: 
  * 역할: ERP의 기본 탑재용 표준 불량 10종(치수, 스크래치, 크랙, 조립, 도금, 소음 등)을 중복되지 않은 항목에 한해 자동으로 일괄 생성합니다. (`DF_{명칭}_STD` 형태로 생성)
* **그리드 컬럼**:
  * **구분**: 불량 분류(수입, 중간, 출하, AS)가 배지 형태로 표현됩니다.
  * **코드**: 불량 코드의 고유 키.
  * **불량명(원인명)**: 불량명 텍스트 표시. 시스템 자동 표준 등록본의 경우 노란색 **[자동]** 배지가 동반됩니다.
  * **관리**: **[삭제] (쓰레기통 아이콘)** 버튼. 클릭 시 사용자 확인 창(`confirm`)을 거쳐 불량 코드 마스터에서 완전히 삭제합니다.

---

## 3. 핵심 비즈니스 로직 및 제약 사항
* **불량코드 자동 생성**: 코드를 임의 기재하지 않았을 때 한글 특수문자를 제거(`_` 처리)한 뒤 난수를 결합하여 유니크한 키(`DF_...`)를 자동 형성하는 파싱 로직이 동작합니다.
* **표준 불량 세트 유효성 검사**: 벌크 등록 시 이미 동일한 불량명과 카테고리로 매칭되는 마스터 레코드가 등록되어 있다면 덮어쓰지 않고 제외하는 방어 로직이 수행됩니다.
* **수입검사 대상 연동**: `qa_target_parts`에 도큐먼트 ID 형태로 바인딩된 부품은 발주 입고 시 자동으로 검사 대기 리스트(`receiving` 컬렉션의 WAITING_INSPECTION)에 등록되도록 연계 작동합니다.
