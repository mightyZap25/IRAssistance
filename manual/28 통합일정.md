# 통합 일정 관리 (Calendar) 사용자 매뉴얼

통합 일정 관리는 개인의 할 일(Tasks), 담당 이슈(Issues), 전사 공정 스케줄(Projects) 및 승인된 임직원의 근태/휴가(Attendance) 일정을 하나의 달력 뷰에 결합하여 직관적으로 제공하는 전사 일정 통제 센터입니다.

---

## 1. 개요 및 권한 정책

*   **메뉴 경로**: 사이드바 ➡️ **공통 / 협업** ➡️ **Calendar (통합 일정)**
*   **주요 역할**: 개인 할 일 마감일 트래킹, 할당된 이슈 데드라인 모니터링, 프로젝트 단계별(Stage) 시작/마감 일정 조회, 전사 근태/휴가 동향 파악, 간이 할 일 등록.
*   **권한 요구사항**:
    *   **전사 임직원 (User/Manager/Admin)**: 본인에게 할당된 태스크/이슈 및 전사 공정/근태 일정을 누구나 자유롭게 조회하고 본인 일정을 등록할 수 있습니다.

---

## 2. 화면 구성 및 레이블 정의

### 2.1 상단 네비게이션 및 좌측 필터
*   **오늘**: 클릭 시 현재 날짜가 포함된 년/월로 달력을 즉시 리셋합니다.
*   **이전달/다음달 버튼**: 한 달 단위로 일정을 앞뒤로 이동 탐색합니다.
*   **일정 필터 토글**: 좌측 체크박스를 클릭하여 캘린더 그리드 상에 노출할 데이터 소스를 제어합니다.
    *   **근태 및 휴가** (초록/파랑): 연차, 시간차, 공가, 출장, 외근, 재택 등.
    *   **프로젝트 마감일** (동적 컬러): 각 프로젝트 단계별 시작 및 종료 마일스톤.
    *   **개인 할 일 (Task)** (보라): 본인이 등록한 일별 개인 태스크 요약.
    *   **할당된 이슈** (빨강): 본인이 담당자로 지정된 ECO 및 품질/설계 이슈 마감일.

### 2.2 월간 캘린더 그리드 구성 레이블
| 레이블명 | 형식 | 설명 |
| :--- | :--- | :--- |
| **날짜 번호** | `9px` 숫자 | 오늘 날짜인 경우 파란색 뱃지(`bg-indigo-600`)로 강조 표시 |
| **한국 공휴일** | `7px` 빨간 텍스트 | 신정, 설날, 삼일절, 추석, 한글날 등 법정 공휴일 자동 표기 및 일요일과 동일하게 날짜를 빨간색으로 시각화 |
| **장기 일정 블록** | 가로 바 (Bar) | 프로젝트 공정 및 출장/연차 등 여러 날에 걸친 다중일 일정은 그리드를 횡단하는 가로 바 형태로 시각화 |
| **공정 진행률** | 그라데이션 오버레이 | 프로젝트 바 좌측에 진행 단계별 완수 백분율(`progress`)을 연한 투명도로 채워 시각적 달성률 표기 |
| **더보기 버튼** | `+ N개 더보기` | 하루에 표시할 수 있는 한계(3개)를 초과하는 일정이 몰릴 경우 노출되며, 클릭 시 해당 일자의 전체 일정 목록 팝업 실행 |

### 2.3 근태 및 휴가 유형 매핑 뱃지
*   **연차/시간차/공가**: `Leave` 카테고리 중 결재 완료 상태인 건에 한해 **초록색(Emerald)** 뱃지로 노출됩니다.
*   **출장**: **하늘색(Sky)** 뱃지로 노출됩니다.
*   **외근**: **청록색(Teal)** 뱃지로 노출됩니다.
*   **재택근무**: **남색(Indigo)** 뱃지로 노출됩니다.

## 3. 세부 제어 기능 및 모달 액션

### 3.1 빈 날짜 클릭 시: 간이 할 일 작성 (QuickTaskCreateModal)
달력 그리드의 빈 공간을 클릭하면 해당 일자가 기본 완료 기한(`dueDate`)으로 사전 설정된 상태로 간이 할 일 추가 모달이 팝업됩니다.
*   **할 일 제목 (필수)**: 추가할 태스크 내용.
*   **중요도 설정**: 중요도에 따라 캘린더 내 아이콘 및 색상칩이 달라집니다.
*   **성공 처리**: 저장 완료 시 자동으로 캘린더가 갱신되어 새로고침 없이 일정을 확인할 수 있습니다.

### 3.2 일정 블록 클릭 시: 일정 세부 모달 (WorkspaceEventDetailModal)
캘린더에 렌더링된 일정 뱃지를 클릭하면 일치하는 데이터 형식에 맞춰 세부 모달이 팝업됩니다.
*   **프로젝트 스케줄**: 상위 프로젝트명, 현재 공정율, 단계 명칭(Stage ID), 시작/종료 예정일을 조회합니다.
*   **개인 할 일 요약**: 해당 날짜에 지정된 전체 태스크 수와 그 중 완료된 개수를 표시하며, 클릭 시 세부 태스크 완료 체크가 가능합니다.
*   **근태/휴가**: 기안 임직원 이름, 부서, 신청 카테고리, 신청 사유 및 구체적인 연차 사용 기간을 안내합니다.
*   **할당 이슈**: 품질 부적합 NCR 등 연계된 이슈 번호와 심각도 및 액션 가이드를 노출합니다.

## 4. 데이터 연동 및 DB 매핑 정보

### 4.1 Firestore DB 연동 구조
통합 일정을 구성하기 위해 아래의 Firestore 컬렉션을 동시 탐색(Cross-Query)합니다.
*   **개인 할 일**: `tasks` 컬렉션에서 `assignedTo === currentUserId` 조건을 필터링하여 완료 여부(`status === 'completed'`)에 맞춰 요약합니다.
*   **프로젝트**: `projects` 컬렉션의 각 문서 내 `schedules` 오브젝트(시작일 `start`, 마감일 `end` 문자열 값)를 로드하여 바인딩합니다.
*   **이슈 관리**: `issues` 컬렉션에서 `assignedTo === currentUser.email` 이메일이 매치되는 항목 중 마감일(`dueDate`)이 명시된 문서를 검색합니다.
*   **근태/결재**: `attendance_requests` 컬렉션에서 기안 결재 상태가 승인 완료(`Status === 'Approved'`)된 연차/외근/출장 문서를 실시간 스캔하여 달력에 렌더링합니다.
