# 구글 챗 연동 (Google Chat) 사용자 매뉴얼

구글 챗 연동 메뉴는 전사 팀원 간의 소통 장벽을 낮추기 위해 외부 메신저 서비스인 Google Chat을 ERP 협업 캔버스 내에 실시간 임베딩하여, 업무 화면 전환 없이 즉시 메시징 및 채널 협업을 진행할 수 있는 메신저 게이트웨이입니다.

---

## 1. 개요 및 권한 정책

*   **메뉴 경로**: 사이드바 ➡️ **공통 / 협업** ➡️ **Google Chat (메신저)**
*   **주요 역할**: ERP 시스템 내 Google Chat 화면 임베딩을 통한 실시간 채팅, 미디어 파일 전송, 음성/영상 회의 권한 연동 및 새 창 바로가기 제공.
*   **권한 요구사항**:
    *   **전사 임직원 (User/Manager/Admin)**: 본인의 회사 구글 계정으로 로그인되어 있는 환경이라면 제한 없이 모든 채널 및 다이렉트 메시지(DM)를 사용할 수 있습니다.

---

## 2. 화면 구성 및 레이블 정의

### 2.1 상단 가이드 밴드 및 바로가기
*   **보안 및 로그인 안내 배너**: Google Chat 프레임이 정상 로드되지 않거나 404/보안 거부 에러 발생 시 대처 방안(구글 계정 로그인 상태 확인 및 브라우저 쿠키 보안 정책 완화 제안)을 안내하는 컴포넌트입니다.
*   **새 창에서 열기 버튼**: 클릭 시 브라우저의 새 탭을 열어 Google Chat 공식 웹 서비스([chat.google.com](https://chat.google.com/))로 즉시 이동합니다. 브라우저 보안에 의해 프레임 내 로드가 차단된 경우 폴백(Fallback) 수단으로 적극 활용됩니다.

### 2.2 메신저 캔버스 영역
*   **Google Chat Iframe**: Google Chat의 오리지널 화면을 동일하게 렌더링합니다.
*   **허용된 미디어 권한**: Iframe 내 원활한 업무 통화를 위해 아래의 하드웨어 및 API 접근 권한이 브라우저 수준에서 사전 승인 연동되어 있습니다.
    *   카메라 (`camera`)
    *   마이크 (`microphone`)
    *   화면 공유 (`display-capture`)
    *   전체화면 모드 (`fullscreen`)
    *   오디오 자동 재생 (`autoplay`)

## 3. 하이브리드 환경 분기 및 장애 조치 (Troubleshooting)

### 3.1 데스크톱 앱(Electron)과 브라우저(Web)의 환경 감지 분기
*   본 시스템은 다중 플랫폼을 지원하도록 설계되었습니다.
*   `window.electronAPI.isElectron` 검출을 통해 데스크톱 네이티브 앱(Electron) 내부 렌더러 환경으로 감지된 경우, 일반 `iframe` 대신 앱 단의 보안 네이티브 `<webview>` 태그나 외부 브라우저 핸들러가 가동되도록 본 리액트 렌더러 영역에서는 화면을 일시 차단(`null` 반환)하여 보안 경고 및 리소스 낭비를 방지합니다.

### 3.2 화면 먹통/흰색 화면 장애 조치
1.  **로그인 세션 만료**: 구글 Workspace 계정 세션이 만료된 경우 Iframe 내에 빈 화면이나 에러가 표기됩니다. 이때는 [새 창에서 열기] 버튼을 눌러 구글 계정에 먼저 로그인해 주시기 바랍니다.
2.  **서드파티 쿠키 제한**: 크롬 등 브라우저의 '서드파티 쿠키 차단' 보안 정책이 활성화되어 있으면 구글 도메인과 ERP 시스템 도메인이 달라 로그인이 거부될 수 있습니다. 브라우저 주소창 우측의 '쿠키 허용' 아이콘을 클릭하여 차단을 해제하시거나, ERP 주소를 신뢰할 수 있는 사이트로 등록해 주십시오.
