# 클라우드 메모 (Memo) 사용자 매뉴얼

클라우드 메모는 실시간 구글 드라이브(Google Drive REST API) 연동을 바탕으로, ERP 시스템 내에서 작성한 업무 메모 및 회의록을 클라우드 전용 디렉토리에 HTML 규격으로 즉시 동기화하고 공동 관리할 수 있는 클라우드 연동 메모장입니다.

---

## 1. 개요 및 권한 정책

*   **메뉴 경로**: 사이드바 ➡️ **공통 / 협업** ➡️ **Memo (메모)**
*   **주요 역할**: 실시간 구글 드라이브 동기화, 리치 텍스트 에디터를 통한 마크다운 스타일 메모 편집, 메모 실시간 필터링 검색, 클라우드 메모 삭제 및 신규 생성.
*   **권한 요구사항**:
    *   **전사 임직원 (User/Manager/Admin)**: 본인 회사 계정의 구글 OAuth 인증이 완료된 브라우저 세션 상태라면 누구나 개별 클라우드 메모 생성, 저장, 로드 권한을 보유합니다.

---

## 2. 화면 구성 및 레이블 정의

### 2.1 좌측 메모 리스트 사이드바
*   **새로고침 버튼**: 구글 드라이브 전용 폴더 내 파일 목록을 실시간으로 다시 긁어옵니다.
*   **새 메모 버튼 (Plus)**: 현재 작업 에디터 창을 클리어하고 신규 제목과 본문을 입력할 수 있는 빈 메모 상태로 전환합니다.
*   **검색창**: 키워드를 입력하여 메모 제목 중 일치하는 항목을 실시간 검색 필터링합니다.
*   **메모 카드 구성 레이블**:
    *   **메모 제목**: 실제 클라우드 저장명에서 확장자(`.html`)를 파싱하여 보기 좋게 텍스트만 렌더링합니다.
    *   **최종 수정일**: `modifiedTime` 값을 날짜로 변환하여 시각화합니다.
    *   **메모 용량**: 파일의 크기를 KB 단위로 소수점 한 자리까지 계산해 표기합니다.
    *   **휴지통 버튼**: 메모에 마우스 오버 시 표시되며, 클릭 시 구글 드라이브에서 해당 파일을 영구 삭제합니다.
*   **클라우드 상태 바**: 화면 최하단에 위치하며, 현재 연동 중인 구글 드라이브 타겟 폴더명(`Cloud Sync: IR_Assistant_Memos`)을 명시합니다.

### 2.2 우측 메모 편집기 (Editor Canvas)
*   **제목 입력 필드**: 메모 마스터의 최상단 텍스트 박스로, 입력된 문자열에 자동으로 `.html` 확장자가 붙어 드라이브 파일명으로 저장됩니다.
*   **리치 에디터 (RichMemoEditor)**: 볼드, 이탤릭, 헤더 조정 등 리치 서식 및 마크다운 단축 문법을 지원하는 본문 작성 영역입니다.
*   **저장 버튼 (Save)**: 현재 작업 본문을 클라우드로 업로드합니다. 저장 중에는 스피너 애니메이션과 함께 버튼이 비활성화(`saving`)됩니다.

## 3. 세부 기능 및 구글 API 연동 로직

### 3.1 구글 드라이브 전용 폴더 관리
*   사용자가 본 페이지에 최초 진입 시, 시스템은 구글 드라이브 루트 디렉토리에서 `IR_Assistant_Memos`라는 명칭을 가진 폴더를 자동 스캔합니다.
*   만약 폴더가 존재하지 않는다면 Google Drive Directory 생성 API를 호출하여 백그라운드에서 전용 보관 디렉토리를 생성하고, 고유 `Folder ID`를 확보하여 모든 메모를 해당 경로 하위에 격리 관리합니다.

### 3.2 메모 내용 로드 및 저장 프로세스
*   **내용 조회**: 리스트에서 메모 카드를 클릭 시, `https://www.googleapis.com/drive/v3/files/{file_id}?alt=media` API를 구글 OAuth Access Token과 함께 호출하여 HTML 파일의 원본 Raw 텍스트를 다운로드하고 에디터 본문 상태값에 바인딩합니다.
*   **멀티파트 저장 (Multipart Upload)**:
    *   메모 제목(`metadata`)은 JSON Blob으로 생성하고, 메모 본문(`content`)은 HTML Blob으로 각각 생성합니다.
    *   두 Blob을 `FormData` 객체에 바인딩하여 `multipart/related` 규격으로 구글 파일 저장 API(`https://www.googleapis.com/upload/drive/v3/files`)에 전송합니다.
    *   수정본은 `PATCH` 메소드로, 신규 메모는 `POST` 메소드로 분기 처리되어 실시간 업데이트를 보장합니다.

## 4. 데이터 연동 및 DB 매핑 정보

### 4.1 클라이언트 및 구글 API 연동 매핑
*   **인증 및 토큰 유효성 보장**: `googleService` 라이브러리의 `ensureValidToken()`을 호출하여 만료 1분 미만인 토큰인 경우 무인식 재인증을 수행한 후 아래 API를 적용합니다.
*   **구글 API 엔드포인트 구성**:
    1.  폴더 및 메모 리스트 검색:
        *   `GET https://gmail.googleapis.com/gmail/v1/users/me/messages` (Gmail 연계) 및 `GET https://www.googleapis.com/drive/v3/files?q=...`
    2.  메모 작성/수정 업로드:
        *   `POST / PATCH https://www.googleapis.com/upload/drive/v3/files?uploadType=multipart`
    3.  메모 삭제:
        *   `DELETE https://www.googleapis.com/drive/v3/files/{memo_id}`
*   **데이터베이스 매핑**: 본 서비스는 전용 DB(PostgreSQL/Firebase)에 메모 원문을 저장하지 않고, **사용자 개인의 구글 드라이브 클라우드 영역에 실시간 HTML 자산으로 보관**하므로 사내 DB 용량을 소비하지 않는 하이브리드 클라우드 데이터 구조를 갖습니다.
