# 시스템 환경설정 (Settings) 사용자 매뉴얼

시스템 환경설정은 ERP 전체의 기간계 데이터베이스(PostgreSQL) 접속 관리, 외부 고객 지원 이메일 수집을 위한 메일 서버 연동, 서드파티 서비스 API 관리, 메일 템플릿 및 결재 시스템 통제, 그리고 데스크톱 앱의 실시간 자동 업데이트를 총괄 제어하는 관리자 전용 제어 탑입니다.

---

## 1. 개요 및 권한 정책

*   **메뉴 경로**: 사이드바 ➡️ **Admin Settings** ➡️ **Settings (환경설정)**
*   **주요 역할**: PostgreSQL 동적 커넥션 풀 제어, IMAP 메일 자동 수집 설정, ECount/Google API 키 보관, 메일 자동 생성 템플릿 구성, 결재 워크플로우 통제, 공급사 동기화 스캔 실행, 데스크톱 앱 버전 업데이트.
*   **권한 요구사항**:
    *   **최고 관리자 (Admin)**: 본 메뉴는 최고 수준의 보안 정보 및 시스템 환경 변수를 다루므로 `RoleGuard(requiredRole="admin")`에 의해 차단 보호되며, **오직 Admin 권한을 승인받은 관리자만 진입 및 수정이 가능**합니다. (일반 사원 및 부서 매니저 진입 불가)

---

## 2. 화면 구성 및 레이블 정의

화면은 좌측 사이드바 탭 메뉴와 우측 탭별 상세 제어 폼(Form) 영역으로 구성되어 있습니다.

### 2.1 DB 연동 설정 (PostgreSQL)
*   **프로필 전환 스위처**:
    *   **사내 로컬 접속 Profile**: 회사 내부 인트라넷 환경에서 직접 Synology NAS 등의 DB 서버에 고속 연결하는 프로필입니다.
    *   **외부 원격(Tailscale) 접속 Profile**: 사외 출장이나 재택근무 시 가상 사설망(VPN/Tailscale)을 거쳐 보안 우회 연동하는 프로필입니다.
*   **프로필 복사 단축 버튼**:
    *   [사내 설정을 외부로 복사 📋] 및 [외부 설정을 사내로 복사 📋] 버튼을 클릭하여 호스트 IP를 제외한 포트, 계정 정보를 상호 동기화 전송합니다.
*   **상세 폼 입력 필드**:
    *   **호스트 IP (Host)**: PostgreSQL DB 서버의 IP 주소.
    *   **포트 (Port)**: PostgreSQL 서비스 포트 (기본값 `15432`).
    *   **접속 계정 (Username)**: 데이터베이스 인스턴스 접근 ID.
    *   **데이터베이스 이름 (Database)**: 기본 작업 대상 데이터베이스 명칭.
    *   **비밀번호 (Password)**: 계정 비밀번호 (암호화 보존되며 변경 시에만 기입).
*   **연결 테스트**: 저장 전에 입력한 서버 IP로 직접 핑을 날려 세션을 확인하는 실시간 커넥션 테스트 기능입니다.

### 2.2 A/S 이메일 연동 (CS)
*   고객 기술지원 메일함으로 접수되는 인입건을 ERP 내의 'A/S 작업 태스크'로 자동 변환하기 위한 메일 서버 프로토콜을 바인딩합니다.
*   **입력 필드**: IMAP 호스트 주소, IMAP 서비스 포트(SSL/TLS용 `993` 등), 회사 공용 메일 주소(Username), 2단계 보안 인증용 앱 비밀번호(App Password).

### 2.3 외부 API 연동
*   **ECount ERP 연동**: 회사 생산/경리 데이터 이관 전송을 위한 회사 코드(`COM_CODE`) 및 ECount API 세션/발행 키를 보관합니다.
*   **Google Workspace 연동**: 구글 드라이브, 시트, 이메일 API 호출 시 본인 계정 이외의 시스템 전용 백그라운드 태스크 처리를 위한 API Key를 지정합니다.

### 2.4 이메일/문서 템플릿
*   ERP 내에서 구매 발주서(PO) 발송이나 협력사 단가 견적을 메일로 자동 발송할 때 사용될 기본 메일 제목 양식 및 본문(인사말) 구조를 사전 정의합니다. 제목 기입 시 `{PONumber}`, `{PartName}` 등의 파라미터 예약 키 바인딩을 지원합니다.

### 2.5 결재 워크플로우 설정
*   **결재 우회 (Admin Bypass)**: 관리자가 부재중이거나 설계 변경 ECN의 긴급 적용이 필요한 경우 결재 단계를 스킵하고 즉시 통과시킬 수 있는 마스터 승인 권한 허용 옵션을 토글합니다.

### 2.6 공급사/제조사 동기화
*   ERP 내에 등록된 부품 마스터 DB를 전체 검색하여, 해당 부품의 공급업체(Maker)와 제조업체(Manufacturer) 목록 중 아직 SCM 공급사 대장에 누락된 신규 업체를 자동 검출하여 SCM 데이터베이스에 시딩(Seeding)합니다.

### 2.7 시스템 자동 업데이트 (Electron Update)
*   **현재 버전 표시**: 시스템 가동 시 메인 프로세스에 의해 로드된 현 시스템 빌드 버전 정보를 출력합니다.
*   **업데이트 프로세스 상태 제어**:
    *   `idle` / `checking`: 서버를 대상으로 새로운 릴리즈 버전이 배포되었는지 검사합니다.
    *   `available`: 서버에 신규 버전 검출 시 릴리즈 일시 및 상세 릴리즈 노트를 팝업 표시합니다.
    *   `downloading`: 백그라운드 다운로드를 시작하며 다운로드 백분율을 진행 막대로 표시합니다.
    *   `downloaded`: 다운로드 완료 후 사용자가 원할 때 앱을 즉시 재시작(`restartApp`)하여 강제 인스톨 적용합니다.

## 3. 백엔드 연동 및 DB 매핑 정보

### 3.1 REST API 엔드포인트
*   **DB 설정 로드**: `GET /api/config/db` (비밀번호 보안을 위해 마스킹 처리되어 반환)
*   **DB 접속 검증**: `POST /api/config/db/test` (입력된 매개변수로 서버에 직접 PG 커넥션 풀 초기화를 테스트하여 결과값 반환)
*   **DB 설정 저장**: `POST /api/config/db` (성공 시 Synology NAS 등 대상 데이터베이스 연결 풀 정보가 갱신되어 새로운 서버 데이터가 실시간 연계)

### 3.2 Firebase Firestore 매핑
*   **설정 보관**: 이메일 연동 매개변수, ECount 및 Google API 키, 문서 템플릿 텍스트, 결재 우회 토글 변수 등은 Firestore의 전역 `config` 컬렉션에 영구 보존 및 제어됩니다.
*   **공급사 동기화 스크립트**: [supplierAutoRegister.js](file:///D:/workspace/IR_Assistant/src/services/supplierAutoRegister.js)와 직접 동기화되어 `syncAllPartsToSupplierDB()`가 트리거되면 Firestore 내 `parts` 컬렉션을 순차 검색하여 신규 `vendors`와 `manufacturers` 컬렉션에 자동 마이그레이션 적용을 완수합니다.
